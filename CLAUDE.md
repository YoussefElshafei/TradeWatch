# Project Rules

## File Editing
- You are fully allowed to create, edit, replace, and modify code or project files as needed.

## Git Restrictions
- NEVER run `git commit` or `git push`.
- Staging, committing, and pushing code to remote repositories is strictly reserved for the user.
- You may run read-only git commands like `git status`, `git diff`, or `git log` when inspecting workspace state.
