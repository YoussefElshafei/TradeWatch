# Project Rules

## File Editing
- You are fully allowed to create, edit, replace, and modify code or project files as needed.

## Git Restrictions
- You are allowed to run `git add`, `git commit`, and `git push`.
- Commit messages: plain `git commit -m "message"` — no heredocs, no multi-paragraph bodies unless genuinely needed.
- Never add a `Co-Authored-By: Claude` (or any Claude/Anthropic attribution) line to commit messages or PR descriptions.
- You may run read-only git commands like `git status`, `git diff`, or `git log` freely when inspecting workspace state.
